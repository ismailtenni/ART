# ISMAILTENNI ART
Upload everything in this folder to your GitHub repository folder (ARTSITE), replacing old files. Cloudflare rebuilds by itself.
The database tables are created automatically the first time the site is used - no SQL to paste.
Optional: in Cloudflare > your project > Settings > Variables, add ADMIN_EMAIL = your login email, so you can delete any comment.
Newsletter emails are saved in the D1 table "subscribers" (Cloudflare > D1 > your database > Tables).
